# 💰 Учёт Вкладов

Легкое, быстрое и полностью автономное Windows-приложение для локального учета банковских вкладов и накопительных счетов. Программа создана для тех, кому нужен простой и надежный финансовый инструмент без лишней перегруженности банковских комбайнов и без хранения личных данных в облаке.

## ✨ Основные возможности

* **Полный цикл управления вкладами:** Добавление, редактирование (по двойному клику) и безвозвратное удаление ошибочных записей.
* **Умная Ключевая ставка ЦБ:** Возможность привязать доходность вклада к текущей Ключевой ставке (с указанием надбавки или вычета). При изменении глобальной ставки внизу экрана, доходность всех привязанных вкладов пересчитывается мгновенно.
* **Честная математика:** Автоматический расчет эффективной ставки с учетом ежемесячной капитализации. Наглядный счетчик «Дней до окончания».
* **Удобные фильтры:** Мгновенная фильтрация списка по Банку, Владельцу и Валюте. Автоматический пересчет итогов только для отфильтрованных записей.
* **Архив закрытых счетов:** Отдельное окно для хранения истории отработавших вкладов с возможностью восстановить их в работу.
* **Экспорт и Печать:** * Выгрузка данных в `.csv` (с правильной UTF-8 кодировкой для Excel).
  * Формирование аккуратного отчета для печати на А4 с предварительным просмотром и автоматическим переносом длинных таблиц на новые страницы.
* **Сохранение интерфейса:** Программа запоминает ширину колонок таблиц (и на главном экране, и в Архиве), а также размер и положение окна на мониторе.
* **100% Локально:** Все данные хранятся рядом с программой в простом файле `deposits.json`. Никаких серверов и скрытых отправок.

## 🔥 Что нового в Версии 2.0
Надежная защита данных (AES-шифрование): Возможность запаролить базу данных. Приложение использует криптографический алгоритм AES с генерацией ключа (Rfc2898DeriveBytes), защищая ваши финансовые данные от посторонних глаз. При этом программа «умно» отличает зашифрованные файлы от старых незашифрованных текстовых JSON-файлов.
Поддержка паевых фондов (ОПИФ): Добавлен специальный режим учета для ОПИФов без фиксированной ставки и даты окончания.
Расширенная привязка к Ключевой ставке: Поддержка отрицательных надбавок (дисконтов) к КС ЦБ для гибкой настройки нестандартных накопительных счетов.
Встроенный финансовый калькулятор пополнений: Прямо в окне редактирования вклада доступна кнопка [±], позволяющая быстро прибавить или вычесть сумму пополнения/снятия (с защитой от отрицательного баланса), избавляя от необходимости считать в уме.
Система ручной сверки остатков:
Отдельный столбец с датой последней сверки с банковским приложением.
Интерактивные чекбоксы «Сверено» для контроля актуальности данных (чекбоксы сбрасываются при перезапуске программы для обеспечения нового цикла проверки, а даты надежно сохраняются).
Автоматическая установка даты и галочки сверки при любом редактировании вклада.
Умная фильтрация и фокус:
Добавлен новый фильтр состояния: «Все / Сверено / Не сверено».
Реализовано сохранение выделения строки (Selection Persistence): после редактирования или сверки таблицы фокус автоматически возвращается на отредактированный вклад, предотвращая «улет» списка на самый верх.
Повышенная отказоустойчивость: Безопасный парсинг старых баз данных с пропуском пустых дат (null) для бессрочных вкладов и защита от сбоев при несоответствии элементов интерфейса.

## 🛠 Технологии

* **Язык:** C#
* **Платформа:** .NET / Windows Forms
* **Данные:** Newtonsoft.Json (хранение данных и настроек в JSON)

## 🚀 Установка и запуск

1. Склонируйте репозиторий:
   ```bash
   git clone [https://github.com/VadimLevo/Deposit-Tracker.git](https://github.com/VadimLevo/Deposit-Tracker.git)
   
2. Откройте проект в Visual Studio.

3. Убедитесь, что установлен пакет Newtonsoft.Json (через NuGet Package Manager).

4. Нажмите F5 для компиляции и запуска.
