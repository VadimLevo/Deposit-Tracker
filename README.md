# 💰 Учёт Вкладов

Легкое, быстрое и полностью автономное Windows-приложение для локального учета банковских вкладов и накопительных счетов. Программа создана для тех, кому нужен простой и надежный финансовый инструмент без лишней перегруженности банковских комбайнов и без хранения личных данных в облаке.

## ✨ Основные возможности

* **Полный цикл управления вкладами:** Добавление, редактирование (по двойному клику) и безвозвратное удаление ошибочных записей.
* **Умная Ключевая ставка ЦБ:** Возможность привязать доходность вклада к текущей Ключевой ставке (с указанием надбавки или вычета). При изменении глобальной ставки внизу экрана, доходность всех привязанных вкладов пересчитывается мгновенно.
* **Честная математика:** Автоматический расчет эффективной ставки с учетом ежемесячной капитализации. Наглядный счетчик «Дней до окончания».
* **Удобные фильтры:** Мгновенная фильтрация списка по Банку, Владельцу и Валюте. Автоматический пересчет итогов только для отфильтрованных записей.
* **Архив закрытых счетов:** Отдельное окно для хранения истории отработавших вкладов с возможностью восстановить их в работу.
* **Экспорт и Печать:** * Выгрузка данных в `.csv` (с правильной UTF-8 кодировкой для Excel).
  * Формирование аккуратного отчета для печати на А4 с предварительным просмотром и автоматическим переносом длинных таблиц на новые страницы.
* **Сохранение интерфейса:** Программа запоминает ширину колонок таблиц (и на главном экране, и в Архиве), а также размер и положение окна на мониторе.
* **100% Локально:** Все данные хранятся рядом с программой в простом файле `deposits.json`. Никаких серверов и скрытых отправок.

## 🛠 Технологии

* **Язык:** C#
* **Платформа:** .NET / Windows Forms
* **Данные:** Newtonsoft.Json (хранение данных и настроек в JSON)


Программа распространяется "как есть". Все финансовые решения принимаются пользователем самостоятельно.
